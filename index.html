02 — Deneyim

İş Deneyimi

Kasım 2025 — Şubat 2026

Manisa Celal Bayar Üniversitesi İŞKUR Gençlik Programı

Staj Komisyonu Görevlisi

  • İŞKUR Gençlik Programı kapsamında Yazılım Mühendisliği Bölümü Staj Komisyonu'nda görev aldım.
  • Staj defterlerini inceleyerek raporlar hazırladım ve öğrencilerin staj yaptığı şehir ve ülkelere ilişkin temel analizler gerçekleştirdim.

Temmuz 2025 — Eylül 2025

Softtech A.Ş.

Yazılım Mühendisliği Stajyeri

  • Müşteri ve POS terminali yönetimi için C# WinForms uygulaması geliştirerek CRUD işlemleri, veri doğrulama ve SQL Stored Procedure tabanlı veritabanı operasyonları gerçekleştirdim.
  • Quartz.NET ile harici API’den User ve Todo verilerini alan zamanlanmış bir Kafka producer-consumer akışı geliştirdim; kayıtları insert/update işlemleriyle senkronize edip süreci logladım.
  • RabbitMQ üzerinden mesaj yayımlayan ve tüketen iki uygulamalı bir producer-consumer akışı geliştirdim.
  • Docker, Kafka ve RabbitMQ kurulumlarıyla uygulamalı çalışmalar yaptım; Grafana ile temel izleme süreçlerini ve yaygın yazılım tasarım desenlerini inceledim.

Eylül 2018 — Haziran 2019

e-Ofis İstanbul

BT Stajyeri

Müşteri ve çalışanlara teknik destek sağladım; farklı lokasyonlarda ağ altyapısı ve yazıcı kurulumlarını gerçekleştirdim.

03 — Projeler

Öne Çıkan İşler

↗

001

E-Ticaret Backend API

Clean Architecture, DDD ve CQRS yaklaşımıyla geliştirilen production-style e-ticaret REST API. JWT refresh token rotation, policy tabanlı yetkilendirme, RabbitMQ ve Outbox Pattern ile güvenilir mesajlaşma; Redis, ETag ve Elasticsearch ile performans odaklı altyapı sunuyor.

.NET 8 Clean Architecture PostgreSQL RabbitMQ Docker / CI/CD
↗

002

Bankacılık Mutabakat Sistemi

Şube ve banka işlem kayıtlarını CSV, TXT veya veritabanı kaynaklarından karşılaştıran web uygulaması. Eksik, mükerrer ve tutar farklarını tespit ediyor; Excel raporlama, rol tabanlı onay-red akışı, işlem geçmişi ve denetim kaydı sağlıyor.

.NET 8 Minimal API PostgreSQL xUnit Docker / Kubernetes
↗

003

LLM Ajanlı Yazılım Geliştirme Platformu

Lisans bitirme tezi. GPT-4 ajanlarını kullanarak C#, Python ve Java dillerinde otomatik birim testi üretimi, kod yorumlama ve arayüz testi senaryoları sunan mikroservis tabanlı platform.

.NET 8 Python / FastAPI Next.js OpenAI GPT-4 PostgreSQL
↗

004

Tiny House Rezervasyon ve Yönetim Sistemi

Kullanıcıların ev arayıp rezervasyon yapabildiği web uygulaması. Kiralama ve ödeme akışı, giriş/rol yönetimi ve temel güvenlik kontrolleri içeriyor.

.NET 8 ASP.NET Core MVC MSSQL
↗

005

Kelime Ezberleme Oyunu

Aralıklı tekrar mantığıyla çalışan mini quiz motoru. Kullanıcıların çalışma ilerlemesini kaydeden panel ve sade arayüz tasarımı içeriyor.

C# ASP.NET MVC JavaScript MSSQL

Blog Sayfası
